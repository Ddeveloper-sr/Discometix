## About

Discometix is an original cosmetics playground inspired by the idea of previewing profile customizations. It is not affiliated with or endorsed by Discord.

## Features

- Live profile preview
- Cosmetic categories and search
- Decorations, frames, effects, and badges
- Randomize and reset controls
- Responsive mobile layout
- No backend required for the starter version

## Run locally

Open `index.html` in a browser, or serve the folder with any static web server:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## Deploy

The repository can be deployed as a static site on GitHub Pages, Vercel, Netlify, or another static host.
